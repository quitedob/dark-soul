# 烬渊 — 敌人图鉴 (Enemy Compendium)

## 分类系统

所有敌人按其灵性本质分类，影响其行为、弱点和烬产出：

| 类型 | 中文 | 描述 | 共同特征 |
|------|---------|-------------|--------------|
| 失魂 (Lost Soul) | Shī Hún | 因循环崩溃而破碎的人类灵魂 | 行为不稳定，灵属性伤害脆弱 |
| 妖 (Yāo) | Yāo | 被烬火疯狂腐化的自然精怪 | 元素亲和力，受克制元素伤害 |
| 精 (Jīng) | Jīng | 因过量吸收烬而活化的物体 | 高物理防御，魔法脆弱 |
| 鬼 (Guǐ) | Guǐ | 有未了之事的怨灵 | 穿墙移动，祈祷伤害脆弱 |
| 仙堕 (Fallen Immortal) | Xiān Duò | 冻结在半成仙状态的修炼者 | 全方位高属性，特定攻击帧期间脆弱 |
| 神兽 (Divine Beast) | Shén Shòu | 被逼疯的圣兽 | 巨量HP，特定弱点 |
| 神 (Divine) | Shén | 真正的神性存在（仅首领） | 每个实体的独特机制 |
