# 烬渊 — 首领图鉴 (Boss Compendium)

## 首领设计原则

每位首领遵循《黑暗之魂》研究中确立的设计原则：
1. **独特身份**——没有两位首领共享机制、视觉设计或叙事角色
2. **可预判攻击**——每次攻击都有可见的前摇和音效提示
3. **阶段转换**——所有主要首领至少有2个阶段，并伴有机制转变
4. **知识整合**——首领是有历史、动机和悲剧的角色
5. **魂器奖励**——每位首领掉落一个以其为主题的独特可装备物品

## 第二章：血将军·刑天 (Blood General · Xíng Tiān)

| 属性 | 详情 |
|-----------|--------|
| **类型** | 神（被腐化的战神） |
| **HP** | 580 |
| **阶段数** | 3（锁链泰坦 → 挣脱狂战 → 荣誉决斗） |
| **伤害范围** | 28-68 |
| **速度** | 3.0 → 4.5 → 3.5 |
| **场地** | 山顶斗兽场，幻影军队观众 |
| **魂器** | 刑天之心 (Xíng Tiān's Heart) |

### 视觉设计
一位无头巨人（12米高），他的躯干覆盖着仪式疤痕，散发着深红色的烬光。他的眼睛在胸口（以乳为目），他的嘴巴在腹部（以脐为口）——完全如《山海经》所述。两把巨战斧被锁链拴在他的手腕上；在阶段2，锁链断裂。

### 阶段1：缚锁刑天 (Chained Xíng Tiān — 100-70%)
刑天被灵锁（铸魂者的封印）束缚。他的行动受限，但攻击命中时异常凶猛。

| 攻击 | 前摇 | 伤害 | 预兆 |
|--------|--------|--------|------|
| **锁链横扫 (Chain Sweep)** | 1.5秒 | 35 | 斧在地面拖行，火花飞溅 |
| **枷锁猛击 (Shackled Slam)** | 2.0秒 | 48 | 双斧过顶，锁链作响 |
| **胸目凝视 (Chest Glare)** | 1.0秒 | 0伤害（眩晕） | 胸口之眼发光——3秒麻痹凝视 |

### 阶段2：破锁刑天 (Unchained Xíng Tiān — 70-30%)
锁链断裂。刑天进入真正的狂战士之怒。观众席上的幻影军队开始吟唱。

| 攻击 | 前摇 | 伤害 | 预兆 |
|--------|--------|--------|------|
| **旋风之怒 (Whirlwind Rage)** | 0.8秒 | 22×5连击 | 双臂伸展持斧旋转——8米半径 |
| **泰坦飞跃 (Titan's Leap)** | 1.2秒 | 52（范围伤害） | 蹲下，然后飞跃穿越场地 |
| **战吼 (War Cry)** | 0.6秒 | 0伤害（恐惧） | 腹部之口吼叫——5秒伤害减益（-20%） |
| **飞斧投掷 (Axe Throw)** | 1.8秒 | 40 | 投出一斧，通过锁链回收 |

### 阶段3：荣誉之决 (Honor Duel — 30-0%)
刑天的愤怒消退为某种更冷酷的东西——认可。他找到了一个值得一战的对手。他丢下一把斧，单手作战，配合玩家的风格。攻击变得缓慢但更精准。伤害增加，但前摇更长并以荣誉预告——他等你准备好再出手。

| 攻击 | 前摇 | 伤害 | 预兆 |
|--------|--------|--------|------|
| **荣誉一击 (Honor Strike)** | 2.0秒 | 68 | 单次从容过顶劈砍。他在挥砍前点头致意。 |
| **反击姿态 (Counter Stance)** | — | 58 | 静止站立，斧横于胸前。若此时被击中，瞬间反击。等他收势。 |
| **最终致敬 (Final Salute)** | 3.0秒 | 80（一击必杀范围） | HP低于10%：举起斧致意，然后最后一次裂地猛击。场地地面开裂。可以闪避——致意动作就是预兆。 |

### 独特互动：狂战士职业
当狂战士玩家进入场地时，刑天暂停。玩家可以跪下（表情）来发起对话而非立即攻击。刑天认出了玩家体内他那份灵魂的碎片。他提供一个选择：
- **以荣誉而战：** 进行标准首领战
- **证明你的愤怒：** 完全跳过阶段1，从阶段2开始，刑天HP为70%——但玩家以满怒气和全程+25%伤害开始

## 第三章：玉面狐·九尾 (Jade-Faced Fox · Nine-Tails)

| 属性 | 详情 |
|-----------|--------|
| **类型** | 妖（被腐化的自然神祇） |
| **HP** | 450 |
| **阶段数** | 3（试探 → 幻境风暴 → 记忆形态） |
| **伤害范围** | 18-52 |
| **速度** | 6.0 → 5.0 → 4.0 |
| **场地** | 月华台，周围有9朵幻梦花 |
| **魂器** | 九尾幻心 (Nine-Tails' Illusion Heart) |

### 视觉设计
真实形态：一只巨大的九尾狐，翡翠绿色的皮毛，眼睛如液态月光。每条尾巴是不同的颜色，代表不同类型的幻象。她美得像捕食者一样——令人着迷且致命。

人形态（阶段3）：一位穿着层叠翡翠色衣袍的优雅女子，面容半掩在透明扇子之后。她的眼睛从不眨眼。

### 阶段1：测试 (Testing the Intruder — 100-70%)
九尾对这个能看穿幻象的闯入者感到好奇。她是在试探你的能力，而非真的要杀死你。

| 攻击 | 伤害 | 预兆 |
|--------|--------|------|
| **尾扫 (Tail Swipe)** | 24 | 单尾扫过，每次0.8秒前摇 |
| **狐火 (Foxfire)** | 18（追踪） | 召唤3个缓缓追踪玩家的狐火球 |
| **雾步 (Mist Step)** | 0（传送） | 融入雾中，在其他地方重新出现 |
| **魅惑凝视 (Charm Gaze)** | 0（效果） | 如果玩家在凝视期间面向她，移动速度减慢50%持续3秒 |

### 阶段2：幻境风暴 (Illusion Storm — 70-30%)
九尾的九条尾巴各自显现不同类型的幻象。场地充满变换的现实。

| 攻击 | 效果 |
|--------|--------|
| **尾分身 (Tail Clone)（每次激活×3）** | 创造3个幻象分身。每个有1 HP。击中分身对玩家造成10伤害反馈。真正的九尾皮毛中有微妙的翡翠闪光。 |
| **梦境吞噬 (Dream Eater)** | 一道紫色能量波。若被击中，玩家进入5秒梦境状态，控制反转且九尾呈现出分身。 |
| **狐嫁 (Fox Wedding)（终极技）** | 50%HP时：场地变为幻影婚礼队伍。幻象宾客填满场地（阻挡移动），九尾从人群中攻击。持续15秒。 |

### 阶段3：记忆之形 (Memory Form — 30-0%)
九尾化为人类形态——具体来说，是玩家角色前世所爱之人的形象（叙事揭示）。她以优雅的武术和借来的记忆作战。

| 攻击 | 效果 |
|--------|--------|
| **记忆一击 (Memory Strike)** | 使用玩家自身的轻攻击动画——22伤害。每次攻击显示一段闪回。 |
| **借来之术 (Borrowed Technique)** | 复制玩家最常使用的特殊能力并用来对付玩家（飞跃、箭雨、元素爆发或超度） |
| **心中所愿 (Heart's Desire)** | 15%HP时：场地展示玩家最渴望之物的幻象（因职业/选择而异）。九尾提出如果你停止战斗就让其变为现实。攻击可打破幻象。静止站立10秒则死亡。 |

### 记忆凝视（互动过场）
50%HP时（阶段2→3转换）：战斗暂停。九尾分享她的记忆——她作为森林温柔守护者在被幻烬腐化之前的幻象。玩家亲身体验她的悲剧。首次游玩不可跳过。在NG+（新游戏+）中，玩家可在此刻攻击直接跳至阶段3。

| 九尾玉簪 (Nine-Tails Jade Hairpin) | 锻造——制作首领武器 |

## 第四章：堕仙·玄霄 (Fallen Immortal · Xuán Xiāo)

| 属性 | 详情 |
|-----------|--------|
| **类型** | 仙堕 (Fallen Immortal) |
| **HP** | 520（所有碎片共享） |
| **阶段数** | 3（神性半身 → 合一形态 → 碎裂意识） |

### 视觉设计
玄霄的真实身躯是一尊冻结在成仙瞬间的身影——右半身为神圣光芒，左半身为腐烂血肉。他的衣袍是高阶修炼者所用：绣着云纹的白绸，如今已污损破裂。他三缕碎裂意识（在4-4和4-5中击败的副首领）绕着他旋转。

### 副首领：玄霄·嗔念 (Wrath Fragment) — 4-4层
纯粹的侵略性。全攻无守。
- HP：120，伤害：45，速度：6.0
- 攻击：冲拳、怒火连击（5连快拳）、碎地
- 击败奖励：嗔念之拳 (Wrath Fist weapon) 武器

### 副首领：玄霄·执念 (Obsession Fragment) — 4-5层
纯粹的防御和仪式。召唤灵卫，激活场地陷阱。
- HP：140，伤害：28，速度：2.0
- 攻击：灵体召唤、仪式陷阱启动、防御屏障
- 击败奖励：执念护符 (Obsession Talisman accessory) 饰品

### 主首领：阶段1 — 神堕二元 (Divine and Fallen — 100-60%)
玄霄的神性半身攻击，腐烂半身被动。

| 攻击 | 伤害 | 预兆 |
|--------|--------|------|
| **天光 (Celestial Beam)** | 32 | 神性半身举手，1.5秒蓄力，横扫光束 |
| **光矛 (Light Spear)** | 24×3 | 召唤三支光矛，依次发射 |
| **衰败脉冲 (Decay Pulse)** | 18 + 持续伤害 | 腐烂半身每30秒脉冲一次——被动范围伤害 |
| **半闪步 (Half-Step)** | 0 | 溶入光芒传送，在其他地方重新出现 |

### 阶段2：归一 (Reunification — 60-30%)
神性与腐烂半身融合。玄霄作为合一存在战斗，在光与衰败攻击间切换。

| 攻击 | 效果 |
|--------|--------|
| **天腐 (Celestial Rot)** | 叠加减益——每次命中降低3%最大HP（最多5层，30秒后重置） |
| **升天一击 (Ascension Strike)** | 光与衰败的合击重砸。48伤害。留下混合治疗/伤害能量区域。 |
| **碎片环绕 (Fragment Orbit)** | 两个副首领碎片独立环绕攻击。HP降低版本。 |

### 阶段3：意识风暴 (Mindstorm — 30-0%)
玄霄的心智完全碎裂。场地陷入混乱——玩家必须识别当前主导人格（嗔怒、执念或核心）并做出相应反应。

| 人格 | 攻击模式 | 对策 |
|-------------|---------------|---------|
| **嗔怒主导** | 激进冲刺、快速连招 | 弹反/闪避，惩罚后摇 |
| **执念主导** | 仪式施法、场地陷阱、召唤 | 打断施法、避开陷阱 |
| **核心主导** | 平衡的光/衰败攻击 | 标准战斗 |

人格每20秒切换。视觉/音频预兆：嗔怒 = 红光 + 咆哮；执念 = 蓝光 + 吟唱；核心 = 白光 + 寂静。

### 首领战后逃亡序列
吸收天烬后，云霄城开始最终崩塌。玩家必须在崩塌平台间导航完成90秒的逃亡序列，使用新获得的重力操控到达安全地面。这是电影化但机制上真实的——玩家可能死在这里，必须重试逃亡（而非重打首领）。

## 第五章：烬渊之主·烛阴 (Lord of the Ember Abyss · Zhú Yīn)

| 属性 | 详情 |
|-----------|--------|
| **类型** | 神（烛龙 / 堕落的铸魂者） |
| **HP** | 800 |
| **阶段数** | 4（龙形 → 人形 → 烬渊核心 → 最终抉择） |
| **伤害范围** | 28-85 |
| **速度** | 因阶段而异 |
| **场地** | 烬座——虚空中的平台 |
| **魂器** | 烛阴之鳞 (Zhú Yīn's Scale) |

### 视觉设计
烛阴的真实形态是一头活体星光之龙。他的身体由无数微小的光点构成——每一个都是因破碎循环而消逝的灵魂。他的眼睛是垂死的太阳。他的声音不是从口中传出，而是同时从四面八方回响。

他的人形态（阶段2）是一个由凝聚光芒构成的瘦高身影，穿着曾是铸魂者仪式礼服的破烂长袍。他的脸庞古老、疲惫，且完全真诚。

### 战前对话（概要）
烛阴不会立即攻击。他说话约3分钟——游戏中最长的对话。他不是发表邪恶演讲的反派。他是一个疲惫的古老存在，向也许是唯一可能理解的人解释自己：

他做过的每一次计算都确认了同一件事：循环正在失效。烬光正在变暗。在宇宙尺度上短暂的时间里，所有灵魂将湮灭于无。他的解决方案是极端的，但那是唯一防止所有意识灭绝的方法。

他不求宽恕。他求的是理解。然后他问：**"换作是你，你会怎么做？"**

### 阶段1：龙形 (Dragon Form — 100-70%)

| **星宿爪击 (Constellation Claws)** | 35×3 | 星图标记在地面上标注爪击区域——1.5秒预兆 |

### 阶段3：烬渊之核 (Core of the Abyss — 40-10%)

| 攻击 | 伤害 | 预兆 |

### 阶段4：终结抉择 (Final Choice — 10-0%)
10%HP时，烛阴跪下。战斗结束。玩家与他在虚空中唯一的漂浮平台上独处。他道出最后的言语：

> *"如此。一个能真正选择的烬裔。不受旧循环束缚。不被我的愿景桎梏。自由。"*
> *"那么选择吧。我已等待五百年，只为看看一个自由的存在会做什么。"*
> *"So. An Ember Scion who can truly choose. Not bound by the old cycle. Not chained by my vision. Free."*
> *"Then choose. I have waited five hundred years to see what a free being would do."*

**三种行动，三种结局：**

| 玩家行动 | 结局 | 结果 |
|--------------|--------|---------|
| 将烛阴的残余烬吸收入自身 | **薪火相传 (Passing the Flame)** | 天之炉重燃。灵魂恢复循环。你消融——你的烬成为新的引火。 |
| 走向王座并坐下 | **守炉人 (Furnace-Keeper)** | 你取代烛阴的位置。永恒守望。在你沉默的注视下，诸领域缓缓愈合。 |
| 击打王座直至其粉碎 | **大寂灭 (The Great Silence)** | 天之炉被摧毁。不再有循环。灵魂自由——自由地生、死，并真正终结。 |

可用结局可能受5-3关（轮回之路）选择的影响。在所有记忆中选择了暴力的玩家可能被锁定无法选择结局A（牺牲）。表现出仁慈的玩家可能被锁定无法选择结局C（毁灭）。
