# 天赋技能系统 (Talent Skill System)

## 概述

每个职业拥有独特的**天赋树 (Talent Tree)**，包含3层可解锁能力。天赋点数通过提升**道行 (Cultivation Level)** 获得——每级1点。天赋提供永久性的、职业专属的被动加成和主动技能。

---

## 天赋点数经济

| 来源 | 点数 |
|--------|--------|
| 道行等级（每级） | +1 |
| 章节首领击败（首次） | +2 |
| 可选副首领击败 | +1 |
| 秘密天赋卷轴（世界隐藏） | +1每个（全部章节共8个） |
| **理论最大点数** | ~120（Lv.99 + 10首领 + 8卷轴） |

**完整天赋树完成**每职业需要约35点。4个职业全部完成需要约140点——单次游玩无法实现，迫使玩家做出选择。

---

## 天赋层结构（每职业）

### 第一层（新手天赋）
- **要求：** 道行等级1+
- **最大可投入点数：** 9（3个天赋 × 每天赋3点）
- **解锁第二层条件：** 第一层花费3点
- **作用：** 核心属性增强，基础玩法风格塑造

### 第二层（熟练天赋）
- **要求：** 第一层3点 + 道行等级10+
- **最大可投入点数：** 6（2-3个天赋 × 每天赋最多3点）
- **解锁第三层条件：** 第一、二层合计花费5点
- **作用：** 机制深度、协同效应、新能力

### 第三层（大师天赋）
- **要求：** 第一、二层合计5点 + 道行等级25+
- **最大可投入点数：** 3（3个天赋 × 每天赋1点）
- **作用：** 改变游戏规则的顶点能力，定义职业的终极技能

---

## 天赋重洗

玩家在第二章后可在任何烬龛处重洗天赋点数：

| 重洗 | 费用 |
|--------|------|
| 首次重洗 | 免费 |
| 后续重洗 | 等级 × 50 烬 |
| 按职业重洗 | 是——重洗一个职业不影响其他职业 |

重洗费用鼓励深思熟虑地构建，同时允许尝试。

---

## 跨职业天赋协同

当玩家在多个职业的天赋树中投入点数后，**协同加成**将被解锁：

| 投入 | 协同加成 |
|-----------|---------------|
| 狂战士5点 + 神射手5点 | 两个职业 +8%物理伤害 |
| 玄法师5点 + 祝祷师5点 | 两个职业 +10%专注池 |
| 狂战士5点 + 祝祷师5点 | 解锁战巫 (War Shaman) 混合职业 |
| 神射手5点 + 玄法师5点 | 解锁魔弓手 (Arcane Archer) 混合职业 |
| 狂战士5点 + 神射手5点 | 解锁修罗 (Asura) 混合职业 |
| 玄法师5点 + 祝祷师5点 | 解锁阴阳师 (Yin-Yang Master) 混合职业 |

## 天赋UI设计

天赋树界面使用**卷轴 (scroll)** 美学：
- 卷轴横向展开以呈现天赋树
- 每个天赋节点是一个圆形印章中的**篆书 (seal script)** 字符
- 已投入的天赋以烬火之光发光；未投入的为暗淡的石头灰色
- 悬停时显示工具提示，以墨笔书法描述
- 顶部计数器显示可用点数

---

## 平衡哲学

天赋遵循以下设计规则：
1. **没有"必点"天赋**——每个第一层选项对不同玩法风格都是可行的
2. **第三层天赋强大但具有场景性**——不是常驻增益，而是应对特定挑战的工具
3. **跨职业协同是奖励而非要求**——混合职业完全是可选的
4. **重洗可访问但费用足够高，使选择有意义**
5. **没有任何天赋以绕过核心机制的方式使游戏变简单**——天赋增强而非替代玩家技能
