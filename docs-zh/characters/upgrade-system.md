# 角色升级系统 (Character Upgrade System)

## 概述

烬渊使用**多层次升级系统**，结合了传统的魂系 (Soulslike) 属性升级与中国修炼哲学。进度以**道行（Cultivation Level）** 衡量，升级仅在**烬龛 (Ember Shrines)** 处进行。

---

## 核心系统

### 1. 道行提升 (Cultivation Leveling)

主要的进度机制。玩家在任何烬龛处花费累积的**烬 (Embers)** 来提升**道行 (Dào Háng — 修炼等级)**。

| 机制 | 详情 |
|----------|--------|
| **资源** | 烬（从敌人获得、世界中发现、首领奖励） |
| **地点** | 任何已激活的烬龛 |
| **消耗递增** | 等级 × 100 烬（Lv.1→2：100，Lv.2→3：200，以此类推） |
| **最高等级** | 99（60级为软上限——60级后消耗变为3倍） |

**每级收益：**

| 属性 | 每级收益 | 备注 |
|------|---------------|-------|
| 最大HP | +5 | 线性增长 |
| 最大体力 | +2（每奇数级） | 即平均+1/级 |
| 最大专注 | +2（每偶数级） | 即平均+1/级 |
| 天赋点数 | +1 | 用于天赋树 |

### 2. 经脉系统 (Meridian System)

受中国**气功 (Qigong)** 和经络理论启发的次要升级路线。玩家使用在世界中发现的稀有物品解锁和强化**经脉 (meridian channels)**。

**奇经八脉 (Eight Meridians)：**

| 经脉 | 中文 | 解锁物品 | 效果 |
|----------|---------|------------|--------|
| 任脉 (Conception Vessel) | Rèn Mài | 第一章发现 | +10%受到治疗 |
| 督脉 (Governing Vessel) | Dū Mài | 第二章发现 | +10%体力恢复速度 |
| 冲脉 (Penetrating Vessel) | Chōng Mài | 第二章发现 | +8%暴击率 |
| 带脉 (Belt Vessel) | Dài Mài | 第三章发现 | +10%装备负重 |
| 阴跷脉 (Yin Heel Vessel) | Yīn Qiāo Mài | 第三章发现 | +8%闪避无敌帧窗口 |
| 阳跷脉 (Yang Heel Vessel) | Yáng Qiāo Mài | 第四章发现 | +10%移动速度 |
| 阴维脉 (Yin Linking Vessel) | Yīn Wéi Mài | 第四章发现 | +10%专注恢复速度 |
| 阳维脉 (Yang Linking Vessel) | Yáng Wéi Mài | 第五章发现 | +5%所有造成伤害 |

每条经脉可升级5次（等级1-5），需要越来越稀有的材料：

| 等级 | 材料 | 效果提升 |
|-------|----------|----------------|
| 1 → 2 | 灵气结晶 (Spirit Energy Crystal) ×3 | 基础效果的+50% |
| 2 → 3 | 灵气结晶 ×8 | 基础效果的+100% |
| 3 → 4 | 纯阳石 (Pure Yang Stone) ×5 | 基础效果的+150% |
| 4 → 5 | 龙脉精髓 (Dragon Vein Essence) ×3 | 基础效果的+200% |

### 3. 魂器强化 (Soul Vessel Reinforcement)

每个章节首领掉落一个**魂器 (Soul Vessel)**——随玩家成长的独特装备物品。魂器可在烬龛处强化：

| 强化等级 | 烬消耗 | 效果 |
|--------------|-------------|--------|
| +1 | 200 | 基础效果+20% |
| +2 | 500 | 基础效果+40% |
| +3 | 1000 | 基础效果+60%，解锁次要效果 |
| +4 | 2000 | 基础效果+80% |
| +5 | 4000 | 基础效果+100%，解锁终极效果 |

### 4. 武器锻造 (Weapon Forging)

第二章之后，玩家可以使用从击败敌人和首领获得的材料在**铁心工坊 (Iron Heart Forge)** 锻造和升级武器。

| 升级等级 | 所需材料 | 效果 |
|--------------|-------------------|--------|
| +1 → +3 | 铁精 (Iron Essence) | 每级+10%基础伤害 |
| +4 → +6 | 灵铁 (Spirit Iron) | 每级+12%基础伤害 |
| +7 → +9 | 龙鳞石 (Dragon Scale Stone) | 每级+15%基础伤害 |
| +10 | 铸魂碎片 (Soul-Forge Shard) | +20%基础伤害，解锁武器技 |

## 升级经济总览

| 系统 | 资源 | 入口限制 | 最高等级 |
|--------|----------|----------|-----------|
| 道行 (Cultivation) | 烬 | 烬龛访问 | 99（软上限60） |
| 经脉 (Meridians) | 稀有世界物品 | 章节进度 | 每经脉5级（共40级） |
| 魂器 (Soul Vessels) | 烬 | 首领击败 | 每魂器+5 |
| 武器 (Weapons) | 锻造材料 | 铁心工坊（第2章起） | +10 |
| 防具 (Armor) | 锻造材料 | 铁心工坊（第2章起） | +5 |
| 天赋 (Talents) | 天赋点数 | 道行等级 | 因树而异 |

## 死亡与资源持久性

遵循魂系惯例：

| 死亡时 | 状态 |
|----------|--------|
| 携带的烬 | 作为失魂印记 (Lost Soul Mark) 掉落在死亡位置 |
| 已存入（已花费）的烬 | 安全——不会丢失 |
| 道行等级 | 安全——永久 |
| 经脉升级 | 安全——永久 |
| 魂器强化 | 安全——永久 |
| 武器/防具升级 | 安全——永久 |
| 已花费天赋点数 | 安全——永久 |
| 未花费天赋点数 | 安全——不会丢失 |

## UI/UX设计

在烬龛处休息时，升级菜单提供四个选项：

1. **提升道行 (Cultivate)**——等级提升
2. **经脉修炼 (Meridian Training)**——升级经脉
3. **强化魂器 (Reinforce Soul Vessel)**——升级首领灵魂物品
4. **天赋修行 (Talent Cultivation)**——花费天赋点数

菜单使用中国书法风格的标题和水墨过渡效果。
