# 狂战士 (Kuáng Zhàn Shì) — Frenzied Warrior

> *"血未尽，战不休。"*
> *"While blood remains, the battle does not end."*

## 职业身份

狂战士遵循**刑天 (Xíng Tiān)** 之道——那位即使在斩首后仍继续战斗的无头巨人，以乳为目，以脐为口。这些战士将痛苦转化为力量，随着生命值降低而变得更强。当其他职业撤退治疗时，狂战士**向前冲锋**。

**玩法风格：** 高风险、高回报的近战战斗。擅长以伤换伤并靠伤害维持生存。奖励激进的打法，惩罚犹豫不决。

## 战斗风格：刑天斧 (Xíng Tiān Axe)

狂战士使用**双持战斧**，并具有怒气积累机制：

| 动作 | 输入 | 体力消耗 | 描述 |
|--------|-------|-------------|-------------|
| **狂暴劈砍 (Savage Chop)** | 轻攻击 | 18 | 单斧挥砍（26伤害）。快速可连击组合（最多4连击）。 |
| **撕裂猛击 (Rending Slam)** | 重攻击 | 36 | 过顶双斧猛击（52伤害）。高硬直。1.2秒蓄力带霸体。 |
| **狂战冲锋 (Berserker Rush)** | 风格技能 (F) | 22 | 双臂伸展持斧向前冲刺8米，伤害路径上所有目标（18伤害）。 |
| **血祭 (Blood Price)** | 特殊 (G) | 0体力，消耗15%当前HP | 消耗HP立即充满怒气槽。30秒冷却。 |
| **战吼 (War Cry)** | 防御 + 重攻击 | 0 | 范围战吼（5米），击退附近敌人。20秒冷却。 |
| **处决 (Execution)** | 防御 + 轻攻击 | 24 | 缓慢过顶劈砍（1.5秒蓄力）。对HP低于25%的敌人造成三倍伤害。 |

### 怒气机制 (Rage)

狂战士的核心机制。一个次要计量条（0-100），通过以下方式填充：
- 造成伤害：每次命中 +3 怒气
- 受到伤害：每次被击中 +5 怒气
- 击杀敌人：每次击杀 +15 怒气
- 血祭：瞬间获得100怒气（消耗15%当前HP）

**怒气消耗：** 当怒气达到50+时，战士进入**狂暴状态 (Frenzy State)**：
- +20%移动速度
- +25%攻击伤害
- -15%所受伤害
- 体力恢复速度 +40%
- 狂暴期间怒气以8/秒消耗
- 怒气降至0时狂暴结束

## 职业被动：愈战愈勇 (Battle-Forged)

对同一敌人的每次连续命中使对该敌人的伤害增加3%（最多叠加至30%，若6秒内未命中该敌人则重置）。

## 剧情整合

狂战士的血脉可追溯到崇拜刑天为战神的凡人战士。当刑天在与天炉守卫的战斗中阵亡（第二章揭示此情节）时，他的狂战士灵魂分裂成碎片，如今附着在各领域的战士身上。玩家的狂战士正携带着这样一块碎片——这既是他们力量的源泉，也是他们的诅咒。

在第二章中，遭遇被腐化的刑天作为首领时，会产生独特的互动：狂战士玩家可以**沟通**他的灵魂而非立即战斗，获得特殊对话和一条替代路线。

## 中国文化参考

| 要素 | 参考 |
|---------|-----------|
| 职业名称 | 狂战士——"疯狂的战士"，源自中国北方武术传统 |
| 核心神话 | 刑天——出自《山海经》，不屈意志的终极象征 |
| 怒气机制 | 怒气——基于中国传统战斗之怒的概念 |
| 天赋名称 | 以乳为目，脐为口——直接引自《山海经》描述刑天之变 |
| 哲学 | 视死如归——战士对死亡的坦然接受 |
