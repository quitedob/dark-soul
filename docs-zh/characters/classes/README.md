# 角色职业 (Character Classes)

## 概述

烬渊提供 **4种初始职业**，每种都具有独特的中国文化身份、玩法风格和天赋树。玩家在开始时选择一个职业，并在第一章之后可以在烬龛（Ember Shrines）解锁**切换职业**的能力。

所有职业共享相同的核心战斗机制（蓄力/施展/恢复、体力（Stamina）、闪避、锁定），但通过以下方面进行区分：
- **初始属性**（HP（生命值）、体力、专注（Focus））
- **初始武器和战斗风格**
- **独特天赋树**（天赋技能）
- **初始法术/祈祷**
- **职业专属被动能力**

---

## 职业总览

| 职业 | 中文名称 | 角色 | 战斗风格 | 武器 | 专精 |
|-------|-------------|------|-------------|--------|----------------|
| **神射手** | Shén Shè Shǒu (Divine Marksman) | 远程输出 | 羿弓术 (Yi Archery) | 弓 + 匕首 | 远程伤害、元素箭矢、陷阱部署 |
| **狂战士** | Kuáng Zhàn Shì (Frenzied Warrior) | 近战坦克/输出 | 刑天斧 (Xíng Tiān Axe) | 双持战斧 | 霸体、怒气机制、吸血 |
| **玄法师** | Xuán Fǎ Shī (Mystic Mage) | 法师输出 | 五行术 (Five Elements Arts) | 法印 / 法杖 | 元素魔法、范围伤害、群体控制 |
| **祝祷师** | Zhù Dǎo Shī (Invocation Master) | 辅助/治疗 | 天祝术 (Celestial Invocation) | 念珠 / 符纸 | 治疗、增益、减益、灵体召唤 |

---

## 可解锁进阶职业

在完成第三章后，玩家可能通过结合两种职业的要素来发现**混合路线**：

| 混合职业 | 组合 | 名称 |
|--------|------------|------|
| 阴阳师 (Yīn Yáng Shī) | 玄法师 + 祝祷师 | 毁灭与治愈之术的平衡 |
| 战巫 (War Shaman) | 狂战士 + 祝祷师 | 战斗祈祷与自我增益战士 |
| 魔弓手 (Arcane Archer) | 神射手 + 玄法师 | 魔法灌注箭矢 |
| 修罗 (Asura) | 狂战士 + 神射手 | 无情的近中距离混合体 |
