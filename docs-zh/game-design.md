# Ashen Hollow — 游戏设计 (Game Design)

## 愿景 (Vision)

**Ashen Hollow** 是一款原创第三人称动作游戏垂直切片，内容为穿越月光下废墟圣殿、开启被遗忘的捷径并击败守护其封印之心的构装体。

该项目仅借鉴广泛流派规范：刻意的近战出招时序、耐力限制动作、死亡后可回收的资源、重置敌人的检查点、可读的敌人攻击前摇，以及空间捷径。其设定、名称、布局、角色、几何体、代码、材质、声音和表现均为原创。

## 玩家体验 (Player Experience)

原型应创造10-15分钟的游戏循环：

1. 在烬火神坛处休息并学习操控。
2. 穿越第一庭院，控制耐力对抗一名守卫者。
3. 探索岔路以升起捷径大门。
4. 击败或绕过另外两个守卫者。
5. 进入下层竞技场面对烬火守护者。
6. 死亡后返回神坛，权衡回收失落的烬火是否值得冒险。

## 战斗支柱 (Combat Pillars)

### 出招承诺 (Commitment)

攻击有前摇、判定帧和后摇阶段。玩家可以在早期前摇中调整朝向，但不能取消每个失误。重攻击消耗更多耐力且暴露时间更长，以换取更高伤害和硬直。

### 可读性 (Readability)

敌人实体在前摇期间会变亮，武器移动到可读的准备姿态，声音强化判定打击。伤害绝不应在无动画或位置提示的情况下到达。

### 资源压力 (Resource Pressure)

移动是免费的，而冲刺、攻击和闪避消耗耐力。消耗性动作后恢复暂停。清空耐力条会移除玩家最安全的应对手段，使得过度承诺变得危险。

### 恢复 (Recovery)

闪避在较长的移动状态中包含短暂的无敌帧。它是时序工具而非永久免疫。治疗主要在检查点可用；烬火仪式战斗风格提供有限的例外 — 以30灵力消耗和0.92秒吟唱治疗24生命，使其成为高承诺的战术选择而非安全网。

## 成长 (Progression)

击败敌人奖励**烬火**。死亡时将所有携带的烬火掉落为死亡位置的**失魂回声**。死亡还会将所有普通敌人重置至其出生位置。触碰回声恢复数量。再次死亡替换先前的回声。

在已激活的烬火神坛处休息提供**生命锻造**选项：消耗烬火以永久增加最大生命值，每级+10HP（最多3级，消耗50/120/250烬火）。此升级在死亡和应用重启后持久保留，为死亡-恢复循环提供了渐进的锚点。

烬火神坛更新重生点，恢复生命和耐力，并复活普通敌人。捷径在当前应用运行期间保持开启，即使死亡后也能奖励空间进度。

## 遭遇设计 (Encounter Design)

- **Hollow Sentinel（虚空守卫者）：** 基础近战构装体，接近、发动一次攻击前摇并退回后摇。
- **Cinder Guardian（烬火守护者）：** 更大的构装体，更多生命，更长攻击距离，专用血条，以及随距离变化的攻击选择（近距离横扫，中距离交替快速/延迟打击，远距离突刺）。生命降至50%时，守护者进入更具攻击性的第二阶段，攻击更快、伤害更高，并伴有明显的火焰视觉转换。
- **废墟：** 断墙创造视线变化和分隔敌人的机会。侧翼拉杆通过捷径大门返回神坛方向。

## 调校目标 (Tuning Targets)

| 数值 | 目标 |
|---|---:|
| 玩家生命 | 100 |
| 玩家耐力 | 100 |
| 轻攻击消耗 | 20 |
| 重攻击消耗 | 38 |
| 闪避消耗 | 26 |
| 击败普通敌人所需攻击数 | 3–5次轻攻击 |
| 击败守护者所需攻击数 | 10–15次混合攻击 |
| 锁定范围 | 约18米 |
| 交互范围 | 3米 |

这些数值是原型目标，并非关于任何现有游戏的声明。

## 范围边界 (Scope Boundaries)

该垂直切片有意排除了物品栏网格、装备属性、角色创建、在线功能、对话树、任务、存档槽、消耗品治疗、复杂动画重定向和导入美术资源。这些系统会增加制作成本，而无助于对核心战斗循环的验证。
