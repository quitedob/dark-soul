# 烬渊 — 法术与祷告图鉴 (Spells & Prayers Compendium)

## 法术系统概述 (Magic System Overview)

烬渊拥有两种基于灵力的能力系统：

### 法术 (Spells) — 智力/道术魔法
通过法印 (Spell Seals)、法杖或法剑引导。基于道家五行理论和玄门修炼术。主要为攻击性和功能型。

### 祷告 (Prayers) — 信仰/佛法祈愿
通过念珠 (Prayer Beads)、符咒或法器引导。基于中国佛教和民间宗教信仰实践。主要为治疗、增益和灵体相关。

## 设计理念 (Design Philosophy)

1. **无冗余法术** — 每个法术/祷告都有独特的战术定位
2. **横向扩展而非纵向升级** — 后期法术并不是严格更强的；它们提供不同的能力
3. **章节主题整合** — 每个章节的法术反映其元素和主题特性
4. **资源紧张** — 强力法术消耗大量灵力，迫使策略选择
5. **文化真实性** — 法术名称和效果植根于实际的中国魔法/宗教传统
