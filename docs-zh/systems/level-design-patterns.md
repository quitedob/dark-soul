# 关卡设计模式 (Level Design Patterns)

## 设计理念 (Design Philosophy)

烬渊的关卡遵循项目中《黑暗之魂》研究确定的 **FromSoftware 设计原则**，并加以中国建筑与山水传统改编：

1. **相互连通的空间与捷径** — 关卡自身形成回环
2. **环境叙事** — 每个物件的摆放都讲述一个故事
3. **可预知的危险** — 陷阱和危险有可见/可听的预警
4. **安全区域（神坛）** — 设置在挑战之前、恶战之后
5. **可选探索** — 岔路以独特物品/传说奖励好奇心

## 谜题图鉴 (Puzzle Catalog)

### 类型一：环境操作 (Environmental Manipulation)

**描述：** 改变环境以开辟新路径。

| 谜题 | 章节 | 机制 |
|--------|---------|-----------|
| 镜光对齐 | 1-3 | 旋转镜面将光线导向封印门 |
| 阀门关闭 | 1-4 | 拉下两个阀门关闭毒雾 |
| 战旗顺序 | 2-5 | 按历史战斗顺序升起旗帜 |
| 烽火点燃 | 2-4 | 点燃烽火影响下一关敌人行为 |
| 天体表盘 | 4-1 | 旋转浮空阶梯片段使之对齐 |
| 炼药配方 | 4-2 | 向三口丹炉投入正确材料 |
| 重力锚点 | 5-2 | 按几何顺序激活四个锚点 |

### 类型二：钥匙门 (Key Item Gates)

**描述：** 寻找并使用特定物品推进流程。

| 谜题 | 章节 | 关键物品 |
|--------|---------|----------|
| 守炉者封印 | 1-5 | 守炉符文 → Boss门 |
| 囚徒钥匙 | 2-3 | 3片钥匙碎片 → 释放灵匠 |
| 祭品基座 | 1-4 | 放置符文于基座 → 开门 |
| 典籍索引 | 4-3 | 找到4本典籍 → 合成修炼功法 |

### 类型三：谜语/知识 (Riddle/Knowledge)

**描述：** 根据环境线索或古典知识回答问题。

| 谜题 | 章节 | 答案来源 |
|--------|---------|-----------------|
| 九尾谜语 | 3-5 | 中国古典诗词，迷宫中可观察的模式 |
| 记忆验证 | 3-2 | 辨别真实与虚假的记忆 |
| 轮回抉择 | 5-3 | 无正确答案 — 玩家的道德选择 |

### 类型四：潜行/回避 (Stealth/Avoidance)

**描述：** 回避而非战斗。

| 谜题 | 章节 | 机制 |
|--------|---------|-----------|
| 狐嫁游行 | 3-3 | 游行期间躲避嫁衣鬼 |
| 烬滩 | 5-1 | 和平绕过亡魂，否则承担后果 |

### 类型五：战斗试炼 (Combat Trial)

**描述：** 特定战斗限制创造解谜式遭遇。

| 谜题 | 章节 | 限制条件 |
|--------|---------|-----------|
| 铸魂者试炼 | 5-4 | 禁止治疗 / 时间限制 / 定点防御 |

## 陷阱图鉴 (Trap Catalog)

### 类型一：压力板陷阱 (Pressure Plate Traps)

**预警信号：** 略微凸起的石板，不同颜色，附近有烧焦痕迹。

| 陷阱 | 章节 | 效果 |
|------|---------|--------|
| 火焰喷口 | 1-2 | 墙壁喷射 — 3秒，15伤害/秒 |
| 坠落闸门 | 1-2 | 闸门下即死 |
| 塌陷地板 | 1-1 | 站立2秒后塌落 |
| 尖刺坑 | 3-1 | 伪装为花坛 |

### 类型二：环境危害 (Environmental Hazards)

**预警信号：** 视觉损伤、音频提示、环境迹象。

| 危害 | 章节 | 效果 |
|--------|---------|--------|
| 毒雾 | 1-4 | 区域内8伤害/秒（可关闭） |
| 发光液体 | 1-4 | 接触20伤害/秒 |
| 不稳定地板 | 1-4 | 奔跑时破裂，行走安全 |
| 燃烧热油 | 2-2 | 油锅可被玩家或敌人打翻 |
| 雪崩 | 2-1 | 声音触发 — 冲刺或大声战斗触发 |
| 狂风 | 4-1 | 将玩家推向边缘 |
| 重力反转 | 5-2 | 突然重力倒转 |
| 烬火间歇泉 | 5-2 | 周期性超热灰柱喷发 |

### 类型三：敌人伏击 (Enemy Ambush)

**预警信号：** 可疑的空房间，中央可见物品，环境线索。

| 伏击 | 章节 | 布置 |
|--------|---------|-------|
| 镜影显现 | 1-3 | 仅通过镜子从背后攻击 |
| 狐火灯笼触发 | 3-3 | 靠近灯笼触发爆发 |
| 书灵群 | 4-3 | 拿错书产生书灵群 |
| 战犬成对 | 2-2 | 一只牵制，一只侧翼 |

### 类型四：陷阱-敌人组合 (Trap-Enemy Combinations)

| 组合 | 章节 | 设计 |
|-------------|---------|--------|
| 士兵 + 火焰喷口 | 1-2 | 敌人在陷阱区巡逻 — 玩家须同时应对两者 |
| 守护者 + 塌陷楼梯 | 4-1 | 敌人击退玩家落入坠落危险 |
| 灯笼 + 游行鬼 | 3-3 | 环境危害 + 定时敌人巡逻 |

## 捷径设计模式 (Shortcut Design Patterns)

遵循《黑暗之魂》捷径哲学：

| 捷径类型 | 示例 | 目的 |
|--------------|---------|--------|
| **单向门** | 从远端打开的门 | 创造"啊哈！"回环时刻 |
| **踢落梯子** | 放下通往上层区域的梯子 | 返回先前区域的垂直捷径 |
| **反锁门** | 从内部打开的门闩 | 将新区域连接至已知安全区 |
| **升降台** | 层级间平台 | 快速返回神坛 |
| **可破坏墙** | 有光线透出的薄墙 | 隐藏捷径 — 观察的回报 |

## 神坛放置指南 (Shrine Placement Guidelines)

| 情境 | 放置规则 |
|---------|---------------|
| 关卡入口 | 每关入口总有一个神坛 |
| Boss门前 | Boss门步行30秒内有神坛，中间无敌人 |
| 恶战之后 | 特别困难的战斗段落之后 |
| 隐藏区域入口 | 可选挑战区域之前 |
| 垂直枢纽 | 主要垂直转换点 |
| **绝不** | 在另一神坛的视线范围内 |
| **绝不** | 在有活跃陷阱的区域 |
| **绝不** | 距离最近神坛超过3分钟路程 |

## 中国建筑整合 (Chinese Architectural Integration)

关卡几何以中国传统建筑为灵感：

| 章节 | 建筑风格 | 关键视觉元素 |
|---------|-------------------|---------------------|
| 1 | 汉代神庙废墟 | 石柱、铜镜、院落布局 |
| 2 | 明代堡垒 | 带垛口的城墙、烽火台、军事营地 |
| 3 | 中国古典园林 | 亭台楼阁、月门、曲径、水景 |
| 4 | 神话天宫 | 云台、玉桥、天界图案 |
| 5 | 宇宙虚空 + 礼器青铜 | 抽象几何、礼器青铜造型、星图 |
