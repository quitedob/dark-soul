The subset is generated by tools/build_interface_font.py from the printable
characters in the current game scripts, scenes and resource data, plus printable
ASCII and the outlined-diamond lock marker (U+25C7). It does not depend on system
font fallback at runtime. Run that tool with --check to detect missing UI glyphs
after adding text. Regeneration requires fonttools and an OFL source font passed
with --source; the tool neither downloads nor modifies the source font.
