# 五章主线因果桥接图

> **文档职责：** 本文件是章节衔接、叙事旗标、NPC 迁移和结局输入的权威来源。章节文档负责关卡内容，`bestiary/bosses-master.md` 负责 Boss 战斗规格，`story/lore.md` 负责世界观正史。

## 主线一句话

玩家是大破碎时由九位陨落铸魂者制造的应急继承者。为了阻止自身轮回印消散，玩家必须回收四块外落烬片，并在每次回收时决定如何处理被碎片扭曲的守护者；这些真实选择最终构成玩家取得炉心裁决权的资格。

## 主角身份与成长弧

1. **第一章 — 工具：** 玩家只知道回收碎片能延缓自身消散，因此接受云游的指引。
2. **第二章 — 见证者：** 玩家发现碎片的“持有者”也是受害者，第一次对“击杀后回收”产生道德责任。
3. **第三章 — 无过去者：** 忆姬证明玩家没有被夺走的童年或前世；玩家必须主动创造身份，而非恢复身份。
4. **第四章 — 继承者：** 炉心敕印赋予权限，但云游的坦白证明旧守护者并不值得盲从。
5. **第五章 — 裁决者：** 资格来自承受每章选择的后果，而非血统、神谕或击败最终 Boss 本身。

## 章节选择旗标

旗标只能由实际章节事件写入；`5-3` 不允许修改历史。

| 旗标组 | 值 | 写入时机 | 5-3 / 终局影响 |
|---|---|---|---|
| `ch1_guardian_fate` | `released` / `preserved` | 巨阙 10% 阶段使用守炉符文 | 释放：九位残影更信任玩家；保留：巨阙核心在终局提供一次防护 |
| `ch2_xingtian_fate` | `honored` / `absorbed` | 刑天终礼后处理战烬 | 荣誉：看台英魂援助；吸收：玩家获得爆发增益，但烛阴增加怒意镜像招式 |

## 内容与运行时边界

当前仓库已经定义五章、28 个关卡 ID、章节拓扑、基础程序化空间外壳和 7 个 Boss 注册项，但尚无可承载本文件的任务、NPC、对话、过场、选择旗标和结局状态机。以上内容是**叙事实现规范**，不是“当前可玩功能”。后续运行时至少需要：

1. `StoryState`：持久化章节选择、支线与 NPC 状态。
2. `QuestState`：触发、阶段、失败/完成和跨章迁移。
3. `DialogueRunner`：条件对白、一次性对白与结局分支。
4. `StoryEventTrigger`：Boss 阈值、拾取物证、关卡出口和过场事件。
5. `EndingResolver`：只读取既有状态，验证四种结局可达性。
