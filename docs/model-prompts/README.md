# 模型提示词库 · Model Prompts (烬渊 / Ember Abyss)

> 本目录是 **md → 图片 → 3D 模型 → Godot** 资产流水线的上游。每个 `.md` 文件是一个模型单元,
> 内含可直接用于图片生成的英文提示词,以及给建模/管线使用的备注。

- **流水线研究:** 见 [docs/research-llm-mcp-3d-godot.md](../research-llm-mcp-3d-godot.md)(TRELLIS / Hunyuan3D / Blender-MCP / Godot MCP)
- **目标引擎:** Godot 4.7.1,资产导出 **GLB**,导入到 `game/assets/models/`
- **当前状态:** 游戏内全部为程序化占位几何体(`character_meshes.gd` / `weapon_meshes.gd` / `enemy_factory.gd`),
  本目录为正式资产生产清单,按优先级逐步替换。

---

## 流水线(三段)

```
① md 提示词文件(本目录)
   ↓ 粘贴 `## 图片生成提示词` 字段
② 生成图片(image-to-3D 的输入图)
   - 要求:单主体、正面、纯色背景、无文字、无第二物体、正视角
   - 工具:Stable Diffusion / Midjourney / 任意文生图(作为概念图)
   - 也可直接文生图 → 交给 TRELLIS / Hunyuan3D-2 的 image-to-3D
   ↓
③ 生成 3D 模型 → GLB
   - TRELLIS / Hunyuan3D-2(image-to-3D)→ 导出 GLB
   - Blender 修模(拓扑 / 权重 / 弱点击破锚点 / 武器挂点)→ 导出 GLB
   ↓
④ 导入 Godot
   - Godot MCP Native(端口 9080)导入到 `res://assets/models/<分类>/`
   - 替换 `character_meshes.gd` / `weapon_meshes.gd` 中的程序化工厂(挂点命名保持:`weapon_tip`、`ExecutionAnchor`、`GrabProfile` 捕获形状)
```

> ⚠️ **图片生成提示词的使用方式:** 将每个 md 里 `## 图片生成提示词` 代码块整段复制进生图工具即可。
> 提示词刻意写成 **英文**,兼容主流生图模型与 TRELLIS/Hunyuan3D 等 image-to-3D 工具。

## 命名规范

| 项 | 规则 |
|----|------|
| 文件 | `<序号>-<中文名>-<英文名>.md`,序号仅代表阅读/生产顺序,不编码章节 |
| 中文名 | 使用设计文档原名(如 `01-神射手-Divine-Marksman.md`) |
| 章节敌人/环境 | 子文件夹 `01-spirit-ruins`…(与 `docs/chapters/` 前缀一致) |
| 禁止 | 不再新增 `e-1`/`a01` 式散落编号 |

---

## 每个 md 必备字段(见 `00-template.md`)

1. **frontmatter** — 名称 / 类别 / 目标格式 / 参考尺寸 / 源文档
2. **一句话概述** — 该模型在游戏里的作用
3. **视觉描述** — 给建模师:体型、服装、武器、标志特征、配色、剪影
4. **图片生成提示词** — ⭐ 英文,可直接粘贴生图
5. **建模备注** — 低模目标、枢轴/挂点、LOD、锚点(弱点击破/处决/抓投)
6. **出处** — 源设计文档链接

## 全局美术语言(写提示词时强制融入)

- **主题:** 烬 / 余烬 / 灰烬与火,衰败的轮回;烬火是角色、护甲、武器、魂器上的标志性辉光
- **文化锚点:** 神射手=后羿射日;狂战士=刑天无头巨神(山海经);玄法师=道门五行/符箓/八卦镜;祝祷师=佛门/民间信仰/念珠/袈裟/因果
- **敌人类型→视觉:** 失魂=残破甲胄的游魂;妖=自然精怪;精=活物化的器物(石/铜/玉/纸/书);鬼=半透明、嚎泣;仙堕=半飞升的躯体恐怖;神=宏大宇宙神性
- **配色:** 烬火橙红;玉障青绿+月光;天崩白绸圣光vs腐朽;烬座星辉蓝黑
- **风格:** 中式暗黑奇幻、低模/风格化、PBR 贴图、轮廓剪影清晰(类魂 Boss 强调剪影)
