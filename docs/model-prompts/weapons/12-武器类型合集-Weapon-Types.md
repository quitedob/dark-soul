## 一句话概述

> 16+ 类通用武器类型的总览提示词库,每类一段基础提示词供批量生图/建模;文末附各章代表命名武器对照表,方便按类型批量替换程序化占位(`weapon_meshes.gd`)。

## 视觉描述

- **覆盖类型:** 直剑 / 大剑 / 巨剑 / 弯刀 / 双弯刀 / 匕首 / 拳套 / 长枪 / 长戟 / 锤 / 连枷 / 弩 / 盾 / 法杖 / 权杖 / 扇(另附弓)。
- **统一美术语言:** 中式暗黑奇幻、旧金属/玉/骨/符纸材质、烬火橙红辉光为标志;每类用剪影区分(直剑细长、巨剑宽厚、长兵长杆)。
- **通用配色:** 暗铁/锈铜为主,烬火橙红点缀(刃缘/符文/焦点),玉与骨做点缀;传奇武器额外带能量细节。
- **通用握持:** 手部挂点统一在握把/柄/剑格;长兵重心偏前、巨剑重心居中。

## 建模备注

- **低模目标:** 各类型 LOD0 约 1.5k–3.5k tris(巨剑/长戟偏上限);LOD1 减半。
- **挂点/Socket(通用约定):** `weapon_tip` 置于攻击端(刃尖/箭口/焦点/锤面),武器特效挂点;手部挂点统一于握把/柄/剑格(保持 `character_meshes.gd` 现有姿势挂点);盾类额外挂点在盾后护臂。
- **碰撞:** 用简单盒/胶囊按轮廓包裹——直剑一根细盒、巨剑长盒、长兵长盒、盾薄盒。
- **贴图:** 2K 常规 / 4K 传奇;Base/Normal/Roughness/Metalness;烬火辉光一律用 Emission。
- **动画:** 长兵重心偏前、巨剑挥动慢且重;双持武器(双斧/双剑/拳套)成对镜像,挂点分左右手。
