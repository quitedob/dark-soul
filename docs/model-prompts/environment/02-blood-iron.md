## 环境概述

铁啸关是一座陷入永恒战争的明式险峻山关。烽火橙红、血色残阳、锻炉金黄为主色,空中飘浮灰烬与火星,远处烽火台升腾烟柱。整体是"永恒的战场"——残酷但光荣。以下每个小节是**可单独建模的防御工事 / 战场景观单体**,用于替换程序化占位几何。
