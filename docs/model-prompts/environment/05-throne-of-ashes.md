## 环境概述

烬座是天炉核心塌缩成的宇宙抽象领域,空间几何不可信任。抽象几何与青铜礼器形状结合,魂河蓝白 + 垂死烬橙,无自然光源,光线来源不明。整体是"一切的终点"——广阔、安静、悲伤而奇异地平静。以下每个小节是**可单独建模的抽象虚空 / 仪式青铜地标单体**,用于替换程序化占位几何。

灰烬沙滩、魂河与巨型魂骸构成的终章入口。
