# 多层关卡改造：需求落实与验证

对应[原始执行要求](../../tasks/enviroment_require.md)及[关卡设计正文](01-multistorey-investigation-levels.md)。本轮修改实际游戏脚本、空间、交互和验证工具；原始要求文件保留原文。21个非Boss关卡有三层室内箱庭，8个Boss前区不套用室内谜题。

工程实现与玩家体验分别验收。当前有实际运行、连续行走和截图证据；没有首次玩家样本，**80%辨识率、解谜时间及递增死亡分布均未验收**。机器记录采用`OPEN`，不以自动化通过数替代人测。

## 十项具体修改

| 要求 | 游戏内结果 | 对应验证 |
|---|---|---|
| 1. 看得见顶层门、门A在15步内、环境解法 | 实际门上的金灯、红金旗、新石门楣；带护栏的两段光井；首碑距门A约10米并直视实体门面；刻痕形状和颜色对应机关 | 21栋静态几何检查；五章三点×三照明共45张原生截图及实际物理射线。玩家辨识率待测 |
| 2. 开门后伏击、回廊巡逻、顶层盾兵 | `interior_pressure`按章生成真实敌人；A未开不释放伏击；顶层首次开门要求盾兵已死；重新出现的敌人不重新锁已开门 | 实际伏击伤害、前后防御差异、死亡门禁与重置检查；冻结AI的行走段另行标明 |
| 3. 三层跳至一层书堆 | 12米真实自由落体，书堆减伤仍扣血；翻滚无敌不能免除落伤 | 连续输入跳落：书堆约10.8生命，硬地基础36；没有落点传送 |
| 4. 二次回刷 | 一层独立遗物可翻检；二层门闩接回局部火堆；顶层屋脊为第二出口 | 实际走近遗物及屋顶全段；掉烬、保存、载入后重跑二层 |
| 5. 打破玉障三连 | 仅`03_02`设置`chamber_violation`：先上楼见空框和盾兵，回一层挂镜归名，再上顶层门 | 保持逻辑0→1→2，实际解谜楼层1→2→1；连续行走，盾兵致死前验证同层且距离≤4米 |
| 6. 每件道具的归属与视线 | `object_lore`逐物登记三项；手持记录、桌上小旗与断杆、撕边封蜡、未干笔；挂镜面向楼梯 | 归属双向检查与局部原生截图。04_03入口两侧是真实天界书架，里面的桌旗属于血铁来物 |
| 7. 撤销原状禁令 | `interior_expansion_mods_v2`明确记录开孔、回路、敌人和变体；允许修改本楼墙体与配置 | 主线路径、原故事物和原敌人继续独立核对，不用“原状保留”阻止这轮新增 |
| 8. 顶层三件套 | 一个固定1余烬拾取点、可批注的矛盾书记夹页、`roof_ladder_id`实际斜梯；第五章可对照此前批注 | 实际钱包只增加1；批注持久记录；门框侧通过现有窗看到实际奖励灯芯，完整护栏保留 |
| 9. 读碑侦察奖励 | 本地`stele_scouted`及一次消耗标记；开A后右侧副本和灯显现10秒，随后消退 | 实际走到碑前并触发；时序、晚读、重复读取、保存失败、载入及卸载检查 |
| 10. 视线及压力验收 | 本地事件日志、解谜中位数、未读碑比例、三层首轮死亡SVG热力图；三点三照明检查 | 自动化事件排除；零玩家数据明确输出“未测”；20名首次玩家及识别口述仍待采集 |

另落实此前九条要求中的**血铁军需室侵入天界书架后**；函件不裁定主线真相。二层门闩存档键为`<level_id>/door_b2_latch`，与原最终归途门禁分开。

## 连续运行证据

Godot 4.7.1，Windows，物理60Hz，时间倍率1。测试存档在内存中隔离。下列记录均来自实际运行，不是估算路线长度。

| 记录 | 结果与边界 |
|---|---|
| `v2-continuous-loops.log` | 五章代表01_02、02_02、03_02、04_03、05_01；516个路点、4498.1米；实际伏击累计55生命伤害；各关重返二层约10.883秒，含呼叫空平台 |
| `v2-revisit-continuous.log` | 01_02、03_02、04_03、05_01；452个路点、3910.9米；实际遗物、读碑显影、固定1余烬和顶层批注交互。03_02三号调查确在一层 |
| `v2-loop-runtime.log` | 82项运行时断言：保存失败回滚、门A前后压力、活盾兵挡门、侦察窗口、回访记录、落伤与残响恢复约束 |
| `v2-navigation-all.log` | 29关真实导航与机关开闭后的路径可达性；当前区域单独核对，避免误用前一关残留导航 |
| `v2-environment-contract.log` | 29条主线路径、844段坡道；敌人无悬空出生。所有关卡真实创建、导航及切换销毁 |
| `v2-campaign_interior_restore_contract.log` | 旧残响在加载另一存档时移除；无余烬快照不携入旧残响；未获得B2门闩的伪造重生点拒绝 |
| `souls-combat-regression.log` | 原敌人战斗回归62项、8个真实命中案例、墙体及Boss投射物；本轮其后未再改共享敌人/玩家战斗函数 |

连续路线在入口有明确标注的观察放置；正式移动段使用游戏输入，无卡住后搬运角色。伏击段运行真实AI，路线段冻结AI。死亡与盾兵致死使用标明的生产伤害注入，**不代表真人战胜盾兵或全战役通关**。新版四关测试在注入盾兵致死前实际走到守兵前。40余烬为测试钱包种子，顶层奖励另按实际增量1检查。

发现并修复了两项实际故障：尸体/延迟进入事件自动捡回刚掉的余烬；加载零残响存档时保留旧场景残响。当前恢复检查包含角色存活、当前残响身份和实际距离，加载新快照先销毁旧残响。最初失败日志仍保留用于核查。
