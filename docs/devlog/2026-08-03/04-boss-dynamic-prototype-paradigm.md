# Boss 动态表现范式提炼：单文件原型（Kimi）→ SCENE-SPECS

**日期:** 2026-08-03（深夜续）
**范围:** 用户提供一份 Kimi K3 生成的「虚空魔像」单文件 HTML Boss（含辉光/狂暴模式/追踪眼/900 粒子），要求提炼进项目 md 规范并与现状对比。

---

## 一、做了什么

1. **保存原型**：`build/glb-models/prototypes/void_golem_boss.html`（单文件，浏览器可直接打开验证）。
2. **提炼进 SCENE-SPECS**（`build/scenes/_shared/SCENE-SPECS.md`）新增两章：
   - **§9 Boss 动态与互动范式**：结构配方（核心+线框壳/面具追踪眼/浮空碎片轨道参数/光环组/地面能量阵/粒子层）、动态动画配方（`dt` 驱动 + 狂暴乘 `speedMul`）、互动与狂暴阶段（平滑插值/屏幕震动/血条/眼睛追踪）、与项目纪律的校准（Bloom 阈值 0.15→≥0.7 等）。
   - **§10 对比表**：单文件原型 vs 项目现状（见下）。
3. **方法论定位**：本仓库 Boss = **静态几何走 GLB（资产层）+ 动态表现走渲染器（表现层）**。§9 是表现层配方；静态骨架子集可提炼为 GLB。

## 二、对比结论（Kimi 原型 vs 项目现状）

| 维度 | void_golem_boss.html | Ashen Hollow 现状 |
|---|---|---|
| 资产形式 | 单文件 HTML + CDN | 85 GLB + 28 场景纯数据 |
| Boss 结构 | 几何即时拼装 | 雕刻工具箱 → scripts/*.mjs → exportRoot 导出 GLB |
| 动态表现 | ✅ 悬浮/脉动/碎片公转/粒子/追踪眼/狂暴/震动 | ⚠️ 静态 + phase 阶段切换（无逐帧动画/粒子/追踪） |
| 交互 | ✅ 点击狂暴 + 血条 | ⚠️ 点击显名 + 数字键切阶段 |
| 后期 | ⚠️ Bloom 1.4/阈值0.15（偏低易糊） | ✅ Bloom 0.5/阈值0.85 + 克制 |
| 纪律 | ⚠️ 无命名/穿模/材质随意 | ✅ §1–§8 + intersect-audit |
| 可接入 | 否（沙盒） | 已接入 28 场景 |

**互补**：原型补项目缺失的**动态表现层**；项目补原型缺失的**资产纪律/管线**。
