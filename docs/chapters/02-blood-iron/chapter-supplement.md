# Chapter 2 Supplement — 精英怪 · 支线 · 风景 · 音乐

## 🌄 风景与氛围 (Scenery & Atmosphere)

### 视觉主题
铁啸关是一座 **明代风格的险峻山关**，建于两座峭壁之间。终年笼罩在战争烟雾与云海之中。白日可见残阳如血，夜晚烽火照亮山脊。

**关键景观元素：**
- **血染山道 (Blood-Stained Mountain Path):** 蜿蜒的山路，两侧堆满生锈的兵器、破碎的攻城器械、以及插在地上的残破军旗。路边有万人坑——堆满白骨的深沟，偶有磷火飘出。
- **铁啸关外墙 (Iron Howl Outer Wall):** 高达30米的城墙，垛口残缺不全。墙面上有巨大的抓痕——什么东西曾试图爬上来。墙顶有投石机和弩炮，有些仍在自动发射。
- **俘虏营 (Prisoner Camp):** 一片被栅栏和铁丝围住的泥泞区域。铁笼中关着枯瘦的魂魄(有些是失魂士兵，有些是平民)。营火旁堆着锻造工具——俘虏被强迫为两方军队制造武器。
- **烽火台 (Beacon Tower):** 七层高的石塔，每层有八个烽火口。塔内有螺旋楼梯，墙壁上满是烟熏痕迹和士兵刻下的遗言。
- **将军营帐 (General's Encampment):** 残破的帅帐，帐内悬挂着褪色的战旗和一张画满标记的作战地图。帐外是阅兵场——地面上刻着深深的脚印和斧痕。
- **刑天斗场 (Xíng Tiān Arena):** 山顶的圆形角斗场，四面是天然石壁，两方幽灵军队分坐两侧看台。场地中央有两道深深的沟痕——刑天的双斧长期拖在地面留下的痕迹。

### 氛围设计
- **光线:** 暖色调为主——烽火的橙红、残阳的血红、锻炉的金黄。阴影浓重，火光闪烁不定。
- **烟尘:** 空中飘浮着灰烬和火星。远处可见烽火台升起的烟柱。
- **声音环境:** 远处传来的金铁交击声、士兵的喊杀声(但看不到具体战斗)、风穿过城墙缝隙的呼啸、锻炉风箱的节奏声。
- **情感基调:** 悲壮、残酷、光荣。这些士兵已经死了，但他们的战斗精神拒绝消散。

## 🎵 音乐设计 (Music Direction)

### 区域背景音乐
**乐器配置:** 战鼓(主导)、号角、磬(石质打击乐)

**曲式结构:**
- **探索段落:** 远处的战鼓声(极低音量，像是从山谷另一侧传来的战斗回响)。偶尔有一声号角划破寂静。磬的敲击声间隔很长(每10-15秒一次)，像是士兵的脚步。
- **战斗触发:** 战鼓从"远处"变为"近处"——音量陡增，节奏清晰。号角转为急促的短音。

**情绪:** 庄严、悲壮、不屈。音乐应该让人联想到"明知会死仍要冲锋"的战士精神。

### 精英怪战斗音乐
- 在区域音乐基础上增加鼓的层次——大鼓、中鼓、小鼓先后进入，形成复杂的节奏叠层
- 击败精英后：所有鼓同时止息一秒，然后一声悠长的号角独奏作为"致敬"

### Boss战斗音乐: 刑天
**乐器配置:** 六面大鼓(围成半圆)、青铜号角、铜钹、编钟

**结构:**
- **Phase 1 (缚锁刑天, 100-70%):** 大鼓以枷锁的节奏击打——沉重、缓慢、受限。号角演奏一段悲壮的旋律(刑天的主题)。
- **Phase 2 (破锁刑天, 70-30%):** 枷锁节奏被打破——鼓点变得狂野而自由。所有鼓同时以不同节奏敲击，营造"失控"的感觉。铜钹以不规则间隔进入。
- **Phase 3 (荣誉之决, 30-0%):** 所有打击乐停止。只剩一面鼓以极慢的节奏敲击(像是心跳)。号角独奏刑天的主题——这一次不是悲壮，而是庄严。如果玩家是狂战士，编钟加入，演奏一段全新的"和解"旋律。
- **胜利:** 号角长鸣，所有鼓同时一击，然后寂静。

## 👹 精英怪 (Elite Monsters)

### 精英怪 1: 炉暴刑具 (Forge-Rage Engine)

**出现位置:** 2-3 俘虏营 — 最深处的锻造大厅

**外观:** 由砧台、锻锤、铁钳和受刑者残魂熔成的巨大刑具精怪。右臂是一柄锻锤，左臂是铁钳，胸腔内挤压着数个被迫锻造的魂魄。它是俘虏营用于控制灵匠的行刑设备，不是铁心本人。

战烬让它不断重复“惩罚停工者”的命令。铁心被锁在锻炉后的封印笼中；摧毁这台刑具才能解除强制锻造印并将他救出。

**战斗机制:**
| 属性 | 数值 |
|------|------|
| HP | 260 |
| 伤害 | 35 |
| 速度 | 2.2 |
| 架势 | 75 |
| 烬奖励 | 150 |

**攻击模式:**
- **锻锤猛击:** 右臂锻锤垂直砸下。38伤害，2s蓄力。砸在地面产生扇形冲击波(6m长, 18伤害)。
- **铁钳夹持:** 左手铁钳前伸夹住玩家(2s束缚)。如果命中，接下来的锻锤猛击必定暴击(翻倍伤害)。挣脱需要快速连按闪避键。
- **淬火蒸汽:** 将锻锤浸入身旁的水槽，产生高温蒸汽云(5m半径, 8s持续, 12伤害/s+视野模糊)。
- **锻剑召唤(50% HP以下):** 从锻炉中拔出一柄刚锻好的炽热长剑。切换为剑+锤双持模式。攻击速度+30%，但失去铁钳夹持能力。
- **神兵出炉(25% HP以下):** 锻炉中升起一柄完美的灵剑。铸魂师停下攻击，凝视灵剑3秒(玩家可自由攻击)。3秒后，他握住灵剑——全属性翻倍，但每秒失去3%最大HP(灵剑在吸取他的魂魄)。30秒后他自动死亡。

**战术要点:** 
- 锻锤猛击有明显的前摇——看到锤子举过头顶就闪避。
- 被铁钳夹住时优先挣脱，不要贪刀。
- 25% HP时的"神兵出炉"是一个道德抉择——在他凝视灵剑的3秒内猛攻杀死他(安全)，还是让他握住灵剑(危险但掉落更好)。让他自然燃尽(30秒内躲避)获得最佳奖励。

**掉落 (取决于玩家在25%阶段的选择):**
- **直接摧毁核心:** 炉暴锻锤 (Forge-Rage Hammer) — 武器，52基础伤害，STR B加成。+20%对精类型伤害。
- **让刑具过载:** 熔炉残核 (Furnace Remnant Core) — 武器强化材料(可将任意武器直接+3)，加 灵剑碎片 (Spirit Sword Fragment) — 饰品，近战攻击附带+8灵属性伤害。
- 55 烬

**相关支线:** 见支线任务1

### 精英怪 2: 双生烽火守将 (Twin Beacon Generals)

**出现位置:** 2-4 烽火台 — 塔顶烽火大厅

**外观:** 两名孪生将军的魂魄，身着完全相同的明光铠。一人持长柄偃月刀，一人持双锏。两人背靠背站立，永远在等待永远不会到来的援军信号。他们生前是驻守烽火台的最后守军——粮尽援绝，仍坚守了四十七天。

**战斗机制:**
| 属性 | 偃月刀将 | 双锏将 |
|------|---------|--------|
| HP | 150 | 140 |
| 伤害 | 30 | 24(×2快速连击) |
| 速度 | 3.0 | 4.5 |
| 架势 | 50 | 40 |
| 烬奖励 | 40 | 40 |

**核心机制——共生:**
两名将军共享一个生命链接。当其中一人受伤时，另一人获得一个短暂的伤害增益(+30%, 5s)。这意味着无脑集火一人会导致另一人变得非常危险。最佳策略是平衡两者的血量。

**攻击模式 (偃月刀将):**
- **横扫千军:** 长柄偃月刀180°横扫。高击退(玩家会被扫飞)。
- **力劈华山:** 跳起后偃月刀劈下。直线冲击波(12m长)。38伤害。
- **回马刀:** 假装逃跑(后退)，然后突然转身刺击。难以预测，但伤害较低(18)。

**攻击模式 (双锏将):**
- **连环双击:** 双锏快速两次点击。每击14伤害，间隔0.3秒(需要精准闪避)。
- **破甲锏:** 单锏蓄力点击。无视玩家30%防御力。28伤害。
- **护兄挡刀:** 如果偃月刀将HP低于30%，双锏将会主动跳到偃月刀将面前替他格挡攻击(正面无敌)。

**联动攻击 (触发条件: 两者距离在5m内):**
- **烽火连天:** 两人同时跃起，偃月刀+双锏同时砸地。全场AOE(8m半径, 45伤害)。有明显的前摇(两人对视点头)——看到这个动作立刻跑远。
- **兄弟合击:** 偃月刀将把玩家击飞→空中双锏将接住连击(一套完整combo, 总伤害~50)。可以用闪避打断。

**战术要点:**
- 将两人分开是关键——用诱饵、冲刺或地形分隔他们(烽火大厅中有可破坏的柱子)。
- 先击破一人后，另一人进入狂暴状态(伤害+50%, 攻速+30%)，但失去了联动攻击能力。
- 先杀双锏将→偃月刀将少了保护，更容易被击中。先杀偃月刀将→双锏将失去联动攻击的最大伤害来源。

**掉落:**
- 偃月刀碎片 (Glaive Fragment) + 双锏碎片 (Twin Mace Fragment) — 武器强化材料
- 烽火兄弟护符 (Beacon Brother Talisman) — 饰品。当附近有友方单位(召唤物/灵魂)时，+15%伤害。
- 各40烬(合计80)

### 精英怪 3: 贪噬军需官 (Gluttonous Quartermaster)

**出现位置:** 2-5 将军营帐 — 军需仓库(隐藏区域，需通过War Banner Puzzle解锁)

**外观:** 一个肥硕的魂魄，身穿已被撑破的官服。他坐在堆积如山的军粮袋上——粮食早已腐烂，但他仍不停地在吃。他的嘴被缝上了一半(生前因贪污军粮被处刑)，吃东西时腐物从缝线处溢出。

这是一个**可选的非战斗精英**——玩家可以通过特定方式"击败"他而完全不进入战斗。

**战斗机制 (如果选择战斗):**
| 属性 | 数值 |
|------|------|
| HP | 300 |
| 伤害 | 22 |
| 速度 | 1.5(极慢) |
| 架势 | 100 |
| 烬奖励 | 130 |

**攻击模式:**
- **呕吐物投掷:** 从嘴中吐出腐烂军粮。6m射程, 18伤害+中毒(8s, 8伤害/s)。命中地面留下毒水洼(持续15s)。
- **滚压:** 缩成一团向玩家滚来(3m宽, 8m距离)。26伤害+击倒。但滚完后有5s硬直(翻不过身)。
- **贪食(自疗):** 停下来狂吃地上的腐烂粮食。每秒回复15HP，持续5s。可以被打断。
- **粮食山崩(50% HP以下):** 军粮山倒塌，整个房间被腐烂粮食淹没——玩家移动速度-40%，同时出现持续毒素伤害(4伤害/s)。军需官反而获得移动速度+50%(在粮食中游泳)。

**非战斗解决方案:**
在2-1到2-5中收集三份**干净军粮 (Clean Rations)** (隐藏在各个角落)。将军粮交给军需官→他第一次吃到干净的食物，痛哭流涕。他的魂魄在感激中消散，无需战斗。

**掉落:**
- 战斗击杀: 军粮库钥匙 (Quartermaster's Key) — 打开仓库中的宝箱(内含 150烬 + 将军护手)
- 和平解决: 干净军粮的余香 (Fragrance of Clean Rations) — 饰品，+15%治疗药效果。另外军需官的魂魄在消散前告诉玩家刑天帐篷中的一处隐藏军情(揭示了War Banner Puzzle的答案线索)。
- 无论哪种方式: 50烬

## 📜 支线任务 (Side Quests)

### 支线 1: 铁心的救赎 (Iron Heart's Redemption)

**触发条件:** 在2-3俘虏营中找到一本**铁心的日记 (Iron Heart's Journal)**，藏在锻造大厅的一个上锁箱子中(钥匙在守营鬼卒身上掉落)。

**任务流程:**
1. 阅读铁心的日记——了解他曾是铁啸关最受尊敬的铸剑师，但在围城期间被迫为敌人铸造武器，以换取俘虏的性命。他被自己人称作叛徒，却一直活到大破碎后，只为保护仍有意识的灵匠。
2. 摧毁精英怪“炉暴刑具”。如果读过日记，铁心会从封印笼中喊出刑具核心的过载规律。
3. 在25% HP的“神兵出炉”阶段，选择直接摧毁核心，或让刑具握住灵剑后坚持30秒使其过载。两种方式都能救出铁心；过载方式保留更多锻造材料。
4. 收集三段笼钥，解除铁心与其他灵匠身上的强制锻造印。铁心交出**铁心之锤**作为烬龛锻造权限凭证。
5. 铁心迁移至已激活的烬龛网络，成为永久锻造 NPC。

**任务奖励:**
- **铁心之锤 (Iron Heart's Hammer):** 关键物品，解锁烬龛武器锻造与强化
- **铁心的遗作 (Iron Heart's Final Work):** 可将一件武器重新指定伤害类型和缩放属性一次
- **铸魂师之证 (Soul-Smith's Seal):** 饰品，武器强化费用-20%
- 200烬
- 解锁成就: **“锻炉不熄”**

**叙事意图:** 铁心不是等待玩家超度的怪物，而是战争创伤中的幸存者。他把“为敌人锻造”的污名转化为帮助玩家终止战争的实际能力。

### 支线 2: 失踪的斥候 (The Missing Scout)

**触发条件:** 在2-1血染山道的起点处，发现一具较新的尸体(与周围的古尸不同——盔甲较新，身边有一封未寄出的信)。

**任务流程:**
1. 阅读**未寄出的信**——一名斥候写给山外家人的信。信中说他发现了"一条绕过正面战场的安全路径"，但需要"在下次烽火信号发出前验证"。信未写完。
2. 在2-1至2-4中寻找斥候留下的标记:
   - 2-1: 一棵树上刻有箭头(指向隐藏的捷径)
   - 2-2: 一处城墙垛口下压着一块红色布条(标记了弩炮的死角)
   - 2-4: 烽火台第三层的一处角落里有斥候的补给袋(含回复药和情报纸条)
3. 在2-4烽火台顶层，选择点燃烽火——但这会触发斥候情报中提到的"埋伏"(更多的敌人出现)。击败增援敌人后，在塔顶找到斥候的最终遗言。
4. 斥候在遗言中揭示: 他发现了通往刑天斗场的密道，但被敌人发现。他在临死前将密道入口的位置刻在了烽火台的一块松动的砖上。

**任务奖励:**
- 密道钥匙——解锁2-5中的一条捷径(绕过大部分敌人直接到达Boss门前)
- **斥候斗篷 (Scout's Cloak):** 轻甲胸衣。特殊效果——在非战斗状态下，敌人察觉范围-30%。
- 解锁成就: **"无声的奉献"**

**叙事意图:** 另一个"未完成的故事"。斥候不是战士，但他用斥候的方式做出了贡献。玩家继承他的发现——这是魂系经典的"前人栽树后人乘凉"叙事模式。

### 支线 3: 烽火协议 (The Beacon Protocol)

**触发条件:** 在2-4烽火台中找到一本**烽火通信手册 (Beacon Signal Manual)**。

**任务流程:**
1. 手册记载了烽火台之间通信的暗号规则——不同的点火顺序代表不同的军令。
2. 烽火台有四个烽火口(北、东、南、西)。通过点燃特定的烽火口组合，可以向山谷另一侧的废弃烽火台发送信号。
3. 正确的暗号(手册中加密了——需要解码): 北→南→东→西→北(代表"请求援军")。按照这个顺序点燃→远处的烽火台亮起回应。
4. 远处的烽火台中出现了援军的魂魄——一支鬼魂部队穿过山谷来到铁啸关。他们不会直接帮助战斗，但会:
   - 在所有后续区域中增加友方NPC魂魄(不被敌人攻击)
   - 在Boss战"刑天"中，看台上的幽灵军队从两方变为三方——玩家的援军在看台上为自己助威(剧情效果)

**任务奖励:**
- **烽火号令旗 (Beacon Command Flag):** 饰品。使用烽火号角道具时，召唤的幽灵盟友持续时间翻倍(120s)。
- 解锁成就: **"烽火连营"**
- 剧情影响: 在5-3的"轮回歧路"中，多了一个可以"验证"的记忆——援军的到来。

**叙事意图:** 战争不仅仅是杀敌。通信、后勤、联盟——这些同样是战争的一部分。让玩家用智慧(而非武力)来改变局面。
