## 1. 事件概要（公开事实）

**胖猫事件**（2024 年 5 月于中国互联网爆发）是一起引发全国性讨论的悲剧性事件。公开报道与重庆警方通报共同确认的要点：

- **男方**：网名「胖猫」、实名刘某，21 岁，湖南临武人，生前在重庆；职业为与网络游戏相关的陪玩/直播（报道口径不一）。
- **女方**：谭某，27 岁，重庆石柱人。两人以真实身份网恋并交往 **两年多**，互见亲友、有过线下往来，警方认定是**真实恋爱关系**。
- **经济往来**：网传「胖猫向谭某转账约 51 万元、自己省吃俭用」的说法流传极广；但警方通报**未以净额口径确认该数字**，并明确**不构成诈骗犯罪**、排除杀猪盘/勒索。两人互有转账。
- **时间线**：2024-04-11 凌晨胖猫发「我们已经结束了」后于重庆长江大桥跳江；04-23 遗体在长寿区长江水域打捞确认，排除刑事案件。
- **网络反应**：长江大桥出现大量鲜花、奶茶等悼念物；多家奶茶/外卖商家（茶百道、华莱士等）卷入争议（如悼念单"空包"配送丑闻）。谭某遭**大规模网暴与个人信息泄露**，官方与媒体介入治理网络谣言。
- **社会讨论**：恋爱脑/舔狗叙事、性别对立、网络审判、消费主义、网暴治理等议题成为舆论焦点。

## 2. 关键发现（按可信度排序）

| 发现 | 可信度 | 依据 |
|---|---|---|
| 两人是真实恋爱关系，非诈骗/杀猪盘 | **高** | 重庆警方通报 + 央视/澎湃复述 |
| 跳江与打捞时间线（04-11 / 04-23） | **高** | 警方通报、主流媒体一致 |
| 事件引爆大规模悼念、商家争议、网暴 | **高** | 多源一致 |
| "51 万转账"的具体数字口径 | **中** | 网传广泛但官方未给统一净额 |
| 事件被用作性别对立/网络审判议题 | **高** | 媒体专题与评论大量讨论 |

## 3. 适配判断：为什么放在第三章

烬渊第三章「玉障·迷心」的叙事核心是**真伪难辨**：九尾保存了被天界篡改的大破碎见证，忆姬负责辨认真伪（见 `docs/story/chapter-bridge-map.md` §五章因果链）。胖猫事件的核心张力恰恰是：

- **网络版本的"故事" vs 警方核实的"事实"** —— 对应第三章的伪史主题；
- **悼念群众的悲愤被导向错误目标** —— 与本章"受害者也可能是加害者""被安上罪名的清白者"的主题完全同构；
- **忆姬的证词** 可作为现成的"核实者"NPC，无需新增系统。

因此把改编放在第三章作为第 4 个支线（`桥头的供茶`），复用 3-4 镜花水月亭场景与忆姬。

## 4. 改编设计（去实名 · 神话自洽）

详见 `docs/chapters/03-jade-veil/chapter-supplement.md` 支线 4。要点：

- **原型转译**：陪玩/恋人转账 → 烬茶倌把全部烬寄给"心中那个人"；长江大桥 → 3-4 镜花水月亭断桥；奶茶悼念 → 桥头供茶；茶百道等商家 → 桥头茶摊茶魂；"罪人"被冤 → 悼念者欲封魂无辜茶魂；真正榨取者 → 贪烬鬼（以爱为饵的掠食者）。
- **双分支选择**（对齐游戏既有 FateChoice/旗标惯例）：
  - `bridge_tea_exposed = true`（证伪·释怀）：揭穿贪烬鬼、渡茶、救茶魂、贪烬鬼精英战；
  - `bridge_tea_mob = true`（随波逐流）：顺众怒封魂茶魂、吸收怒烬、贪烬鬼潜行。
- **5-3 轮回歧路回响**：两分支在该处产生不同的记忆投影（平静道谢 / 敌对的歧路影），对齐 `samsara_stance` 段旗的"只改对白/视觉，不改写历史"契约。

## 5. 寓言层（潜台词，可读作现实批判）

> 注：本层只作为**神话内的潜台词**存在，不进入 UI 文案；明面剧情保持神话自洽。

- **旧秩序 = 失败的系统**：天界（旧秩序）的轮回正在衰竭，但它不愿承认自己不行。
- **制造对立 = 转移追问**：贪烬鬼与旧秩序暗中同行——它最乐见不同族属、不同"派系"的悼念者互相指责。只要愤怒被导向"另一群人"（男女对立、派系相争、价值观之争），就永远不会有人抬头问：**轮回为何在衰竭、谁真正在榨取烬火**。
- **多元的两种用法**：表面上的"多元纷争"被当作耗散群众注意力的戏码；真正的病根（系统性失败）被对立掩盖。支线结局里，证伪路线就是"戳穿戏码、让众人看见真凶"。

这一层让支线在魂系"可悲众生相"之外多一层**关于"分裂如何维护失败权力"**的隐喻，与游戏既有伪史主题（天界删改记录、云游隐瞒责任）一脉相承。

## 6. 伦理与改编边界

该事件是一起**真实的自杀悲剧**。改编遵守以下红线：

- **去实名**：不出现刘某、谭某等真实姓名，不出现真实金额、日期、品牌；
- **不消费死者**：游戏内年轻魂不具喜剧化、猎奇化处理，全程以"未被渡走的轮回"的悲悯基调呈现；
- **不加剧网暴**：支线的"随波逐流"分支明确呈现其代价（茶魂被封、真相被掩、贪烬鬼继续捕食），而非奖励盲从。

## 7. 矛盾与缺口

- 「51 万转账 / 谭某退款」等金额口径：网传与官方不一致，**无法从本次检索确定净额**，报告不采信具体数字。改编也不需要它。
- 警方通报原文（重庆南岸分局）的完整文本未直接抓取，核心定性来自媒体转述 + 维基「胖猫跳江事件」条目。
- 长江大桥悼念现场与商家争议的细节各报道略有出入；改编已泛化为"桥头供茶/茶摊"，不依赖这些细节。
